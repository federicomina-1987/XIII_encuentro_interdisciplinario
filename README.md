# XIII Encuentro Interdisciplinario

> **Sostener lo público como construcción de lo común: soberanía científica y futuro de las ciencias sociales y las humanidades.**
> *Del 22 al 24 de julio de 2026 | Ciudad Universitaria, Córdoba, Argentina.*

Este repositorio contiene el código fuente de la página web oficial y el programa interactivo del **XIII Encuentro Interdisciplinario**, organizado por el Instituto de Humanidades (IDH). La plataforma está diseñada para ofrecer a los asistentes y ponentes una herramienta ágil para navegar por el cronograma, las mesas y las exposiciones del evento.

**🔗 [Visitar el Sitio Web en Vivo**](https://idhinstitutodehumanidades-rgb.github.io/XIII_encuentro_interdisciplinario/?utm_source=gemini#/)


Creado por: Federico Daniel Mina, 2026.

## Características Principales

El sitio web actúa como una aplicación de página única (SPA) para explorar el evento, destacando las siguientes funcionalidades:

* **Motor de Búsqueda Dinámico:** Permite a los usuarios consultar el programa completo en tiempo real.
* **Filtros de Programa Avanzados:** Los asistentes pueden realizar búsquedas específicas mediante tres criterios principales:
* Búsqueda por **Nombre** (Autor/Expositor).
* Búsqueda por **Palabra Clave** (Temática o título).
* Búsqueda por **Coordinador** (Responsable de mesa o panel).
* JSON incluído en el HTML.


* **Diseño Responsivo:** Interfaz adaptada tanto para dispositivos móviles como para pantallas de escritorio, utilizando un sistema de diseño basado en utilidades (utility-first CSS).

Si deseas clonar este proyecto para realizar modificaciones o explorar el código localmente, sigue estos pasos:

1. **Clonar el repositorio:**
```bash

```


2. **Navegar al directorio del proyecto:**
```bash
cd XIII_encuentro_interdisciplinario

```
